# SystemPgm
운영체제를 만드는데 이러한 명령어들을 왜 제공하는가? 에 대한 고찰

시스템 콜(System call) 활용 프로그래밍을 통해 시스템 프로그램을 작성하는
능력을 배양. 프로세스 생성/종료, 파일 생성/삭제/열기/읽기/쓰기 등의
시스템 콜 활용법을 실습을 통해 학습

담당교수 : 김주현

1 주차 - 수업 및 유닉스/리눅스 소개

2 주차 - 리눅스 사용

3 주차 - 리눅스 명령어 및 VIM

4 주차 - C 프로그래밍 환경

5 주차 - 파일 입출력

6 주차 - 파일 시스템

7 주차 - 파일 및 레코드 잠금

8 주차 - 중간고사

9 주차 - 표준 파일 입출력

10 주차 - 프로세스 구조

11 주차 - 프로세스 제어 1

12 주차 - 프로세스 제어 2

13 주차 - API
