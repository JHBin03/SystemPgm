개요 : fork에 대한 정확한 이해

### `fork()` 시스템 콜의 핵심 개념

`fork()`는 현재 실행 중인 프로세스(부모)를 정확히 복제하여 새로운 프로세스(자식)를 생성하는 리눅스/유닉스의 시스템 호출이다.

* **완벽한 복제:** 자식 프로세스는 부모 프로세스의 코드(Code), 데이터(Data), 힙(Heap), 스택(Stack) 공간 및 열린 파일 디스크립터(File Descriptor) 등을 그대로 복사하여 가져간다.
* **분기점 (Fork):** 복제가 완료된 직후, 부모와 자식 프로세스는 모두 `fork()`가 호출된 바로 다음 코드 라인부터 병렬로 실행을 계속한다.

### Copy-on-Write (COW) 최적화

과거에는 `fork()` 호출 시 메모리를 물리적으로 100% 복사하여 시간과 메모리 오버헤드가 컸다. 하지만 현대적인 리눅스 구현체는 **Copy-on-Write (지연 복사)** 최적화 기법을 사용한다.

* 프로세스 생성 직후에는 부모와 자식이 물리적 메모리 페이지를 완전히 공유한다.
* 둘 중 하나라도 자신의 데이터를 수정(Write)하려는 순간, 커널이 개입하여 해당 메모리 페이지만 별도로 복사해 독립적인 공간을 만든다. 이를 통해 프로세스 생성 속도와 시스템 효율이 크게 향상된다.

### 반환값(Return Values)에 따른 분기 제어

`fork()`는 단 한 번 호출되지만, 복제된 두 프로세스에게 서로 다른 값을 반환하여 자신이 부모인지 자식인지 스스로 식별하게 한다.

* **`> 0` (양수):** 부모 프로세스에게 반환되는 값이다. 새로 생성된 자식 프로세스의 PID(프로세스 ID)를 의미한다.
* **`0`:** 자식 프로세스에게 반환되는 값이다. 이를 통해 코드 내에서 if문을 사용하여 자식 전용 로직을 분기하여 실행할 수 있다.
* **`-1` (음수):** 프로세스 생성에 실패했을 때 부모 프로세스에게 반환된다(자식은 생성되지 않음). 주로 메모리 부족이나 시스템 최대 프로세스 개수 초과 시 발생한다.
