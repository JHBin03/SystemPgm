# 프로세스

실행중인 프로그램을 '프로세스'
- 각 프로세스는 유일한 프로세스 번호 PID를 가짐
- 각 프로세스는 부모 프로세스에 의해 생성됨

## 프로세스의 종류

- 시스템 프로세스
- 시스템 운영에 필요한 기능을 수행하는 프로세스
- 사용자 프로세스
- 사용자 명령 혹은 프로그램을 실행시키기 위해 생성된 프로세스

### 데몬 프로세스

사용자와 직접 상호작용 하지 않음. 백그라운드에서 계속 실행. 시스템, 응용 프로그램의 기능을 지원하는 프로세스임.

## 프로세스 명령어

### ps - 프로세스 목록 확인

```bash
$ ps [-옵션]
$ ps -ef
```

**ps 출력 정보:** UID, PID, PPID, C, STIME, TTY, TIME, CMD

### pgrep - 특정 프로세스 검색

```bash
$ pgrep sshd
```

## 작업 제어

### 후면 처리 (Background)

```bash
$ 명령어 &
[1] 프로세스 번호
```

### 쉘 재우기 - sleep

```bash
$ sleep 초          # 명시된 시간만큼 프로세스 실행을 중지
$ sleep 초 &        # 백그라운드로 전환
$ echo 시작; sleep 10; echo 끝    # 시작 - 10초 후 - 끝 출력
```

### 강제종료 / 실행정지

- 강제종료: `Ctrl-C (^C)`
- 실행정지: `Ctrl-Z (^Z)`

### fg - 후면 작업의 전면 전환

```bash
$ fg            # 정지된 작업을 다시 전면에서 실행
$ fg %작업번호
```

### bg - 전면 작업의 후면 전환

Ctrl-Z 키를 눌러 전면 실행중인 작업을 먼저 중지시킨 후, bg 명령어로 후면 작업 전환

```bash
$ bg %작업번호
```

### 후면 작업의 입출력 제어

```bash
$ 명령어 > 출력파일 &
$ find . -name test.c -print > find.txt &
$ find . -name test.c -print | mail chang &
```

## 프로세스 제어 명령어

### kill - 프로세스 끝내기

```bash
$ kill 프로세스번호
$ kill %작업번호
```

프로세스 번호(혹은 작업 번호)에 해당하는 프로세스를 강제로 종료시킴

#### 시그널 보내기

한 프로세스가 다른 프로세스를 제어하기 위해 특정 프로세스에 임의의 시그널을 강제적으로 보냄

```bash
$ kill [-시그널] 프로세스번호
$ kill [-시그널] %작업번호
```

시그널을 명시하지 않으면 SIGTERM 시그널을 보내 해당 프로세스를 강제 종료

### exit - 종료

```bash
$ exit [종료코드]
```

### wait - 프로세스 기다리기

```bash
$ wait [프로세스번호]
```

프로세스 번호로 지정한 자식 프로세스가 종료될 때까지 기다림.
지정하지 않으면 모든 자식 프로세스가 끝나기를 기다림.

## 프로세스 우선순위

실행 우선순위 nice 값: `19 ~ -20` (낮을수록 우선순위 높음), 기본값 0

### renice - 우선순위 변경

```bash
$ renice [-n] 우선순위 [-gpu] PID
```

이미 수행중인 프로세스의 우선순위를 명시된 우선순위로 변경

- `-g` : 해당 그룹명 소유로 된 프로세스를 의미
- `-u` : 지정한 사용자명의 소유로 된 프로세스를 의미
- `-p` : 해당 프로세스의 PID를 지정

## 프로세스의 사용자 ID

### 실제 사용자 ID와 유효 사용자 ID

- **실제 사용자 ID:** 실행시킨 사용자의 ID로 설정됨
- **유효 사용자 ID:** 일반적으로 실제 사용자 ID와 동일

### set-user-id 실행파일

set-user-id가 설정된 실행파일을 실행하면:
- 프로세스의 유효 사용자 ID는 그 실행파일의 소유자로 바뀜
- 실행되는 동안 그 파일의 소유자 권한을 갖게 됨

```bash
$ ls -l /bin/passwd
-rwsr-xr-x. 1 root root 59976 7월 14 14:57 /bin/passwd
# 's' 자리가 set-user-id를 나타냄
```

#### set-user-id 실행권한 설정

```bash
$ chmod 4755 파일
$ chmod u+s 파일
```

### set-group-id 실행파일

실행되는 동안에 그 파일 소유자의 그룹이 프로세스의 유효 그룹ID가 됨.
8진수 모드로 `2000`으로 표현됨.

```bash
$ ls -l /bin/wall
-r-xr-sr-x. 1 root tty 35200 2월 25 2021 /bin/wall
```

#### set-group-id 실행권한 설정

```bash
$ chmod 2755 파일
$ chmod g+s 파일
```
